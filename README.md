# Vehicle Listing Platform

A full-stack vehicle listing application developed for learning modern web application development.

The platform will allow users to create and view vehicle listings. Administrators will be able to review, approve or reject submitted listings.

## Technologies

### Backend

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* PostgreSQL

### Frontend

* Angular
* HTML
* CSS
* TypeScript

### Development Tools

* Docker
* Git
* GitHub

## Planned Features

* List vehicle advertisements
* View advertisement details
* Create a new advertisement
* User registration and login
* Admin dashboard
* Approve or reject advertisements
